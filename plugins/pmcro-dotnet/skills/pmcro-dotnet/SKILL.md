# pmcro-dotnet

Use for .NET engineering tasks inside a PMCR-O workspace.

## Mandatory flow
1. Load the PMCR-O loop and applicable laws.
2. Inspect the target solution, project files, package versions, and existing conventions.
3. For version-sensitive decisions, perform current-state research against authoritative sources.
4. Plan before mutation and define testable acceptance criteria.
5. Implement the smallest coherent change while preserving local architecture.
6. Verify with builds, tests, analyzers, and runtime evidence where applicable.
7. Record evidence and unresolved risks in the active trail.

## Boundaries
- Do not invent APIs, package versions, project structure, or framework behavior.
- Do not replace an existing architecture merely to match a template.
- Do not claim success without verification evidence.
- Prefer official Microsoft/.NET documentation for framework facts.

## PMCR-O integration
The skill supplies technical capability; the PMCR-O Planner, Maker, Checker, and Reflector govern execution. The Checker owns PASS | LOOP | HALT.
